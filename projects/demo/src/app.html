ng-toast

Toast notifications for Angular that stay small: signals and plain timers, zoneless, nothing beyond @angular/core and rxjs. Promise toasts, actions, a queue and a theme that follows Angular Material, in about 3.5 kB of JavaScript. 

npm install @stefankuburovic/ng-toast

This page runs with provideToast({ maxOpened: 4, preventDuplicates: true, countDuplicates: true }).

Zoneless and signals

Plain timers and signals, no NgZone. Works with and without zone.js, on Angular 20.2 and later.

Promise toasts

toast.promise() shows a spinner, then turns the same toast into a success or an error made from the result.

Updates in place

toast.update() changes the text, type and options of an open toast, for uploads and long jobs.

Actions

Buttons such as Undo, with onClick, onAction, your own classes and an aria-label.

Queue and duplicates

maxOpened keeps the screen calm; the rest wait. Repeats are counted on the toast that is up.

Pauses when unseen

Hover stops the timer, and so does a background tab, so nothing disappears before it was read.

Themes by CSS variables

No selectors to out-specify, and a ready theme for Angular Material, light and dark.

Easy to leave ngx-toastr

The API follows the archived ngx-toastr, so moving over is mostly a rename.
